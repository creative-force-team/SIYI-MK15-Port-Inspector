# SIYI MK15 Port Inspector 1.5.5 — миссия для Сергея

**Цель:** один раз аккуратно снять объективную карту физических органов управления SIYI MK15. Ручные таблицы не нужны — приложение само запишет измерения и сформирует ZIP.

## Перед началом

1. Пульт и всё связанное оборудование находятся **на столе**.
2. **Двигатели / силовая установка не работают. В полёте не выполнять.**
3. Закройте QGroundControl и другие программы, которые могут одновременно работать с SIYI Datalink.
4. Откройте **SIYI MK15 Port Inspector**.
5. В заголовке должно быть: **SIYI MK15 · 1.5.5**.
6. На экране должны быть видны вкладки: **Исследование · Отчёт · Диагностика**.

Если версия другая или основных кнопок не видно — испытание не начинать.

## Подготовка

На вкладке **«Исследование»** нажмите **«1. Подготовить»**.

Подождите несколько секунд. В таблице должны появиться живые значения каналов.

Не нажимайте «Подготовить» повторно во время текущей серии без необходимости: приложение хранит уже завершённые опыты текущего сеанса до формирования отчёта.

## Как записывать один орган

Для каждого физического органа:

1. В поле **«Орган»** выберите нужное имя.
2. Проверьте поле **«Вид»**:
   - A, B, C, D → BUTTON;
   - SA, SB, SC → SWITCH_3POS;
   - LD, RD → ANALOG;
   - J1–J4 → STICK.
3. Нажмите **«2. Записать»**.
4. Двигайте **только этот один физический орган**.
5. Выполните указанные ниже циклы.
6. Нажмите **«3. Завершить»**.
7. Только после этого переходите к следующему органу.

Если неожиданно меняются несколько каналов — **ничего вручную не исправляйте**. Закончите опыт как есть: это полезный результат.

## Порядок опытов

### 1. C — контроль

- выбрать C (контроль);
- нажать **2. Записать**;
- сделать **5 полных циклов нажатие → отпускание**;
- нажать **3. Завершить**.

Ожидаемый известный ориентир:

- C → CH10;
- отпущено около 1050;
- нажато около 1950.

Если C внезапно показывает совсем другое поведение, закончите этот опыт, нажмите **Стоп**, перейдите в **Отчёт → Отправить ZIP** и на этом остановите серию.

### 2. D — контроль

То же самое: **5 циклов**.

Ориентир:

- D → CH11;
- отпущено около 1050;
- нажато около 1950.

При радикальном расхождении — сохранить и отправить ZIP, дальнейшую серию не продолжать.

### 3. A

**5–10 нажатий → отпусканий.**

### 4. B

**5–10 нажатий → отпусканий.**

### 5. SA

Несколько раз пройти **все три положения**, не менее **5 полных циклов**.

### 6. SB

Все три положения, не менее **5 циклов**.

### 7. SC

Все три положения, не менее **5 циклов**.

### 8. LD

Пройти весь доступный диапазон:

**один край → другой край → возврат**, не менее **5 раз**.

### 9. RD

То же самое: полный диапазон не менее **5 раз**.

### 10. Остальные кнопки / переключатели / вращающиеся органы

Выбирать OTHER, вводить понятное физическое имя и исследовать **по одному органу за опыт**.

### 11. J1–J4

В самом конце, если нужен полный инвентарь.

Для каждого стика пройти основные направления и диапазон несколько раз. J1–J4 исследуются для идентификации; это не означает, что они будут назначены приложению.

## Завершение

После последнего опыта:

1. Нажмите **«Стоп»**.
2. Перейдите во вкладку **«Отчёт»**.
3. Нажмите **«Отправить ZIP»**.
4. Дождитесь сообщения: **«Отчёт отправлен в thesystem: HTTP 200»**.

На этом миссия закончена.

Если отправка не удалась:

1. нажмите **«Сохранить ZIP»** либо **«Флешка / файл»**;
2. сохраните архив;
3. передайте ZIP Андрею обычным способом.

## Что не нужно делать

- не составлять таблицы вручную;
- не угадывать номера каналов;
- не менять mapping;
- не менять RC-конфигурацию;
- не назначать HOLD / RTH / MANUAL;
- не запускать двигатели;
- не выполнять опыт в полёте;
- не трогать два физических органа одновременно во время одного опыта.

## Что вернуть

Если на экране появился **HTTP 200**, достаточно сообщить Андрею:

> Готово, отчёт отправлен.

Если был сохранён файл вручную — передать сам ZIP.

---

Версия приложения и этот сценарий предварительно программно проверены на том же реальном MK15: интерфейс, живой поток, начало/завершение записи, остановка, формирование ZIP и отправка HTTP 200 прошли автономную приёмку.
